# 🏢 Système de Gestion des Adhérents

Application web réalisée dans le cadre d'un TP : Gestion des membres d'un club développée en PHP/MySQL.

## 📋 Fonctionnalités

- Authentification sécurisée
- Ajout de nouveaux adhérents
- Recherche d'adhérents par nom/prénom
- Modification des informations
- Suppression d'adhérents

## 🛠️ Technologies utilisées

- PHP
- MySQL
- HTML5 / CSS3

## ⚠️ Avertissement

**Ne commitez JAMAIS le fichier `config.php` !**  
Il contient des informations sensibles.

## 🔐 Sécurité

- ✅ Requêtes préparées pour prévenir les injections SQL
- ✅ Validation et échappement des données
- ✅ Sessions sécurisées
- ✅ Fichiers de configuration exclus du versioning
- ✅ Protection contre les attaques XSS
